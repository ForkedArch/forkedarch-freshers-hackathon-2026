# Contributing

Thank you for contributing to the ForkedArch Freshers Hackathon 2026 repository.

This repository contains public event information, rules, resources, and templates. It is **not** where participant hackathon projects are submitted.

## You Can Contribute

- Fix documentation errors
- Improve clarity
- Fix broken links
- Improve templates
- Add useful participant resources
- Suggest organizational improvements

## Workflow

```text
Branch
  ↓
Make your change
  ↓
Check Markdown / links
  ↓
Commit
  ↓
Open Pull Request
```

Prefer clear commit messages such as:

```text
Fix submission instructions
Add GitHub workflow documentation
Improve README structure
Update judging criteria
```

Pull requests should include a clear description and relevant context.

Do not submit participant project code to this repository. Participant projects belong in their designated hackathon repositories.

All contributors must follow [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
